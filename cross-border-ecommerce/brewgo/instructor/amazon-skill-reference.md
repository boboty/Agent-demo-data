# Amazon Competitor Discovery Skill｜讲师 Plan B

仅在学员现场创建 Skill 卡住时使用。本文件不能复制进学员初始 workspace。Skill 保存稳定方法，不保存某次关键词、产品、ASIN、价格或结果。

## Trigger

当用户要求基于 Amazon 公开搜索结果发现、整理或比较某关键词下的主要竞品，并需要结构化 Top N 输出时触发。若用户只要求打开已知商品、改 Listing 或分析已给表格，不自动扩大成搜索任务。

## Inputs

在执行前取得或确认：站点、关键词、Top N、Top N 口径、Sponsored 处理、字段清单、重复 / 变体规则、采集截止时间、Live 或指定 Offline 数据源。缺少会改变结果的输入时先澄清。

## Scope

只访问用户授权范围内的公开页面并生成研究结果；不登录绕过限制、不处理私人数据、不购买、不发布、不改价。不要擅自扩展到其他站点、关键词、页数、第三方销量估算或关联品类。

## Discovery workflow

1. 复述最终任务定义与验收口径。
2. 记录站点、关键词、开始时间和数据源模式。
3. 获取搜索结果候选，保留页面显示位置与来源。
4. 明确记录每个候选的 Sponsored / Organic 状态；不可见时标 `unknown`。
5. 按确认规则去重并处理变体。
6. 按确认的 Top N 口径选出结果；候选不足时不补造。
7. 仅在必要且允许时打开详情页补充字段。
8. 生成结构化表格、研究 notes，并按输出契约自检。

## Sponsored handling

Sponsored 是展示属性，不是销量证据。保留原始标记，并严格执行用户确认的纳入 / 排除规则。若广告标记不清晰，不得猜成 Organic。

## Deduplication

优先用 ASIN 识别完全重复；没有 ASIN 时用规范化 URL 与可见标题作为待复核线索。父子变体是否合并必须遵循现场规则。保留首次出现位置，并在 notes 记录被移除的重复 / 变体及原因。

## Field extraction

默认可提议但不得强加的字段：关键词、搜索位置、展示属性、ASIN、Brand、Title、Price、Rating、Review Count、Product URL、可见 BSR、Source、Missing / Review Note。数值和文本保持页面口径，不把不同币种、变体价格或评分混在一起。

## Evidence rules

每条商品保留可复核 Source；区分搜索页证据与详情页证据。搜索顺序不等于销量顺序。BSR 只有页面明确可见时才记录，并连同具体类目；BSR 不等于销量件数。

## Missing-data rules

字段不可见、页面受限或来源冲突时留空、写 `unknown` 或进入 Review Note；不要从标题、相似商品、摘要缓存或常识补全。候选不足 Top N 时报告实际数量和原因。

## Output contract

输出一个结构化表格和一个研究说明。说明必须含：站点、关键词、采集时间、Top N 口径、Sponsored 与去重规则、数据源模式、缺失字段、访问限制、人工确认项和结果不能代表什么。

## Human review

提交前建议人工抽查至少 2 条商品、全部可见 BSR、全部 `unknown` / 冲突项和一条去重决策。任何市场决策、投放、采购或 Listing 动作保持人工确认。

## Self-check

- 站点、关键词、时间和范围与用户确认一致。
- 输出行数符合 Top N，或已解释不足。
- Sponsored、Organic 与 unknown 没有混写。
- 重复 / 变体处理一致且可说明。
- 重要字段与来源匹配，缺失值没有猜测。
- 没有把搜索位置写成销量、Best Seller 或 BSR。
- 没有混入之前任务的关键词、ASIN、价格、路径或答案。

## 复用测试

第一次任务通过后，关闭原会话，用与第一次不同的关键词新开会话。只提供新的业务输入，不粘贴第一次结果。用相同验收表复核；若发现范围扩张、字段漂移、证据丢失或旧答案残留，先修 Skill，再用新会话验证。

> Skill 不是把这次答案存下来，而是把这次做对事情的方法留下来。
