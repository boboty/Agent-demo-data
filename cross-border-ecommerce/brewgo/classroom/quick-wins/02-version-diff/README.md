# Quick Win 02｜两个版本自动找差异

## 1. 业务场景

供应商先后发来 v3 和 final 两版报价表，SKU 多、字段多，业务人员需要快速知道价格、MOQ、交期、付款与费用到底哪里变了。

## 2. 为什么这个任务值得交给 AI

AI 可以按稳定业务键对齐两版记录，只输出真正变化，并把“发生了什么”与“可能影响什么决策”分开。人不再逐格找不同，只需复核高风险项。

## 3. 工作区有哪些输入

- `input/supplier_quote_v3.xlsx`
- `input/supplier_quote_final.xlsx`

两份表包含多个 SKU 和供应商。final 版调整了单价、MOQ、交期、付款方式和包装费，并包含一条新增与一条删除。

## 4. 课堂操作

复制讲师指令，让 Agent 先识别表头和记录匹配键，再输出变更工作簿与摘要。重点观察它是否区分新增、删除、修改，是否跳过完全未变的记录，以及风险判断是否明确写成“建议人工复核”。

## 5. 预期产出

- `outputs/change-report.xlsx`：变更类型、SKU、供应商、字段、旧值、新值、风险等级和复核建议。
- `outputs/change-summary.md`：变更数量、重点变化、可能业务影响与待人工确认项。

## 6. 一个故意埋入的坑

两版行顺序不同；不能用 Excel 行号硬比。删除的清洁刷与新增的收纳袋也不能被误报成同一条“修改”。

## 7. 验收方法

核对报告只列真实变化：1 条新增、1 条删除、5 条被修改的记录，另有 2 条完全未变的记录不应进入变更明细；原工作簿保持不变。

## 8. 一句课堂收口

以后不用肉眼找两版 Excel 哪里不一样，把注意力留给真正影响采购判断的变化。
