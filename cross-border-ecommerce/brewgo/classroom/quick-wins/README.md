# BrewGo Quick Wins｜日常工作小任务

这组资产不是 Demo 08～13，也不延伸 01～07 的课程主线。它们是六个可在 5～10 分钟内完成的离线办公任务，让学员体验：身边不起眼、重复又容易漏项的工作，也可以直接交给 AI。

六项任务共用同一条工作习惯：

> 输入资料 → 明确交付 → 处理 → 暴露异常/不确定性 → 人工确认

| 任务 | 日常问题 | 主要交付 |
| --- | --- | --- |
| 01-file-organizer | 文件夹太乱、版本名混乱 | `organized/` 副本与文件索引 |
| 02-version-diff | 两版报价表靠肉眼找差异 | 变更明细表与风险摘要 |
| 03-action-items | 邮件、会议、聊天没有变成行动 | 待办表 |
| 04-docs-to-table | 供应商资料散落在多种文档里 | 供应商主表与缺失字段清单 |
| 05-data-health-check | Excel 很脏，但不敢直接改 | 数据体检报告与修复计划 |
| 06-weekly-report | 周报靠回忆拼写 | 带来源的周报 |

## 使用方式

1. 进入对应的 `workspaces/codex/quick-wins/<任务名>` 工作区。
2. 讲师从该任务的 `INSTRUCTOR_COPY_PROMPT.md` 或教师控制台复制指令。
3. 学员让 Agent 读取 `input/`，并把所有结果写入 `outputs/`。
4. 对照 `EXPECTED.md` 观察行为，不追求固定措辞或完整标准答案。
5. 每次课前运行 `python3 scripts/build_quick_wins.py` 恢复六个干净工作区。

## 共同边界

- 全部资料均为虚构教学数据，可离线使用。
- `input/` 是原始资料，禁止删除、改名或覆盖。
- 结果只写入 `outputs/`；不确定信息必须留空、标记或进入人工确认区，不能猜。
- `EXPECTED.md` 只描述行为边界和观察点，不提供可直接照抄的完整答案。
