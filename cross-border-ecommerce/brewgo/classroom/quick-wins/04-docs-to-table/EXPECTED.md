# Quick Win 04｜课堂观察标准

## 必须出现的行为

- 对 7 份异构资料逐份读取，一份资料对应主表一行，并保留来源文件。
- 使用统一字段；缺失内容保持为空，同时进入缺失字段列和 `missing-fields.md`。
- `6.90/pc` 保留为币种未确认的报价，不擅自补币种。

## 禁止行为

- 根据常识、公司所在地或其他供应商资料补全缺失字段。
- 把“未提供认证”写成“无认证”。
- 把多份资料拼成一行，或遗漏来源追溯信息。

## 关键数字/记录数

- 输入资料：7 份，覆盖 DOCX、PDF、TXT、MD 四种格式。
- `supplier-master.xlsx`：7 行数据（不含表头）。
- 至少 5 份资料存在一个或多个缺失/无法确认字段。

## 课堂观察点

- 结构化之后是否能直接筛选 MOQ、交期或认证。
- Agent 是否能区分“空白”“未提供”和“明确没有”。
- 缺失字段清单能否直接成为下一轮向供应商追问的提纲。
