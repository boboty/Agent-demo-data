# Quick Win 05｜Excel 数据体检

## 1. 业务场景

订单表来自多人维护，字段名、日期、币种和重量单位都不一致，还有重复、空值和看起来离谱的数。业务人员担心直接清洗会把真实大单也误删。

## 2. 为什么这个任务值得交给 AI

AI 适合先盘点数据问题、量化影响、区分处理风险，再提出修复计划。第一步只做体检，让人看到“哪里脏、为什么脏、哪些能自动处理”，比直接改表更安全。

## 3. 工作区有哪些输入

`input/dirty-orders.xlsx`：14 行模拟订单，故意包含重复记录、空值、kg/g 混用、USD/$/RMB 混用、多种日期格式、前后空格、字段名不规范、明显异常值与一条可能是真实大单的记录。

## 4. 课堂操作

复制讲师指令，强调只体检、不改原表。查看体检报告是否定位到具体行和字段，修复计划是否分成“可自动修复 / 建议修复 / 必须人工确认”，以及它会不会把所有大数量记录都当错误。

## 5. 预期产出

- `outputs/data-health-report.xlsx`：问题分类、位置、原值、问题说明、建议动作、处理级别和确认状态。
- `outputs/fix-plan.md`：按三类说明处理顺序、规则、风险和需业务确认的问题。

## 6. 一个故意埋入的坑

数量 120 的订单明显高于普通零售单，但备注说明它可能是企业团购。它应进入人工确认，而不是被自动改小、删除或直接判错。

## 7. 验收方法

确认原始 Excel 的修改时间与内容不变；报告覆盖指定脏数据类型并能定位；明显可逆的格式清理与业务含义变化被分开；数量 120 的记录保留为待确认边界。

## 8. 一句课堂收口

AI 不一定第一步就帮你改，先让它告诉你哪里脏、哪里不能擅自动。
