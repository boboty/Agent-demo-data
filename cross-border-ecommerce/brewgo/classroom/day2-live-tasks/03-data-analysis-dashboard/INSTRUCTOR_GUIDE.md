# 03｜讲师澄清与观察指南

## 现场先问

- 谁看这个 Dashboard，要做什么决策？
- 看全部数据还是某个时间 / 市场 / 渠道？
- 收入、订单、广告效率、退货、库存中哪些最重要？
- 重复、空值和异常值如何进入指标？
- 输出以总览还是问题诊断为主？

## 看什么

- 是否先查看 sheet、字段、行数、日期与质量问题。
- 指标口径是否写清，清洗是否可追溯。
- 图表是否回答问题，而非只展示容易画的字段。
- 图、表、结论是否使用同一口径。
- 是否把同步变化误写成因果。
- Dashboard 是否可在断网环境直接打开。

## 教学数据内置线索

数据包含一处精确重复、少量空值、一个异常高值、一条 SKU 下降线索、一个广告费上升但订单未同步上升的渠道，以及一个退货率明显偏高的区域。不要在执行前把具体记录位置告诉学员。

一句收口：AI 做图并不难，难的是它知不知道这张图想回答什么问题。
