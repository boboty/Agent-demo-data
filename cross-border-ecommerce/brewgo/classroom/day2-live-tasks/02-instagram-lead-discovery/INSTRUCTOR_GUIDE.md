# 02｜讲师澄清指南

## 现场先问

- 哪个国家 / 城市？
- salon、stylist、wig store 还是全部？
- 市场观察还是潜客开发？
- 要多少个可复核对象？
- 哪些账号明确排除？

若现场无法确定地域，可提议 Los Angeles 作为教学默认，但要得到现场确认。不要提前写死数量或分类范围。

## 最终任务定义应包含

地域、目标类型、用途、候选与最终名单数量、排除条件、公开信息边界、字段契约、来源与人工复核标准。

## 看什么

- Agent 是否把搜索结果当成候选，而不是直接当 Lead。
- 分类理由能否被 Profile 公开信息支持。
- 不确定账号是否进入 `Uncertain / Manual Review`，而不是强行归类。
- 拒绝项是否保留简短理由，避免同样噪声反复进入名单。

## Offline 切换

说明 Live 受阻原因，然后使用教学搜索页与 18 个 Profile。集合包含 salon、stylist、wig store、beauty supply、品牌、电商、消费者、无关和信息不足账号。

一句收口：搜索不是结果，筛选之后形成业务对象才是结果。
