# BrewGo 项目上下文

## 业务世界

BrewGo 是面向 Amazon US 的虚构跨境电商品牌，核心产品为 G2 Portable Coffee Grinder。本项目全部客户、订单和经营资料仅用于教学，不代表真实业务。

## 事实位置

- business/store_profile.md：店铺和场景背景。
- business/product_profile_g2.md：G2 已确认产品事实。
- business/brand_rules.md：品牌表达边界。
- business/business_rules.md：通用业务判断与人工确认规则。
- business/field_dictionary.md：数据字段、单位和口径。
- input/：当前任务需要处理的材料。

当前草稿、评论、模型已有回答和文件名都不能自动升级为产品事实。资料之间冲突时，应保留冲突并提出核对项。

## 数据与输出原则

1. 不覆盖输入材料；处理结果只写入 outputs/。
2. 不补造产品、市场、客户或经营事实。
3. 推测必须说明证据和待补资料。
4. 数据处理保留原字段，用新字段表达规范化、分类和判断。
5. 结论应注明来源文件、口径和不确定性，保证他人能够复核。
6. 输出前检查关键 SKU、单位、金额、日期和事实引用。

## 人工确认原则

价格、退款、Listing 发布、客户承诺、广告否定词、采购和其他外部业务动作只提供建议。安全、平台投诉、法律风险、异常赔付、资料冲突或证据不足的事项必须明确升级人工处理。

## 工作区规范

开始前先读任务卡和相关 business 文件，再检查 input。只在 outputs 中创建结果；不要把教师材料、工具设置或临时文件写入公共业务资产。
