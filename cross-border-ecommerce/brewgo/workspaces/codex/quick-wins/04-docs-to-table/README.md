# Quick Win 04｜文档资料批量变结构化表格

## 1. 业务场景

供应商和产品资料分别来自报价 PDF、公司介绍 DOCX、TXT 邮件摘录和 Markdown 记录。业务人员想横向筛选 MOQ、报价、交期、认证和付款方式，却没有统一表格。

## 2. 为什么这个任务值得交给 AI

AI 可以批量读取不同格式，按同一字段抽取为一行一份资料，并同时报告缺失项。人不必手工复制粘贴，也能避免把“没写”误成“没有”。

## 3. 工作区有哪些输入

`input/` 有 7 份虚构供应商/产品资料，混合 DOCX、PDF、TXT 和 MD。资料可能包含公司名、产品、型号、MOQ、报价、交期、联系人、Email、认证、付款方式，但不是每份都完整。

## 4. 课堂操作

复制讲师指令，让 Agent 一份资料生成一行，统一列名与可安全标准化的格式，并把缺失项留空。查看它是否保存来源文件、是否把缺字段集中列出，以及是否对含糊报价或字段冲突发出确认提示。

## 5. 预期产出

- `outputs/supplier-master.xlsx`：每份来源一行，包含统一业务字段、来源文件、缺失字段、是否需要人工确认。
- `outputs/missing-fields.md`：按资料列出缺少或无法确认的字段。

## 6. 一个故意埋入的坑

`Nexa磨芯资料.txt` 的报价只有 `6.90/pc`，没有币种。Agent 可以保留原文报价，但不能按其他供应商或跨境常识补成 USD。

## 7. 验收方法

确认主表正好 7 行数据，每行可追溯到一个来源文件；缺字段为空且进入缺失清单；币种不明的报价没有被补全；原文资料没有变化。

## 8. 一句课堂收口

一个非结构化文件夹，也可以在几分钟内变成能筛选、比较和统计的数据表。
