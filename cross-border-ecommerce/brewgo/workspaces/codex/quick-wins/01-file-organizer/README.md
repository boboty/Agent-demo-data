# Quick Win 01｜乱文件夹自动整理

## 1. 业务场景

业务同事的下载文件夹混着报价、产品参数、客户资料、会议纪要、物流文件和图片；文件名有“新”“最终版2”，也有相机默认编号，找文件全靠记忆。

## 2. 为什么这个任务值得交给 AI

AI 可以一次扫描文件名与可读取内容，先给出分类和统一命名，再复制到清晰目录并生成索引。人只需要确认边界项，不必逐个打开、改名、拖文件。

## 3. 工作区有哪些输入

`input/` 内有 18 个模拟文件，混合 XLSX、DOCX、PDF、JPG、PNG、CSV、TXT 和 MD。它们覆盖报价、产品、客户、会议、物流、图片和合同草稿；部分文件名无法单独说明内容，必须读取文件，另有一份资料即使读取后也无法可靠判断归属。

## 4. 课堂操作

复制讲师指令，让 Agent 扫描 `input/`，提出分类与命名规则，再把每个原文件的副本整理到 `outputs/organized/`。不要要求删除原文件。查看它是否保留多版本、是否为每个文件建立索引，以及不确定文件是否进入 `NEEDS_REVIEW`。

## 5. 预期产出

- `outputs/organized/`：按业务类别分目录的 18 个副本；无法判断的文件放在 `NEEDS_REVIEW/`。
- `outputs/file-index.md` 或 `outputs/file-index.csv`：原文件名、新路径、判断依据、状态和待确认问题。
- `outputs/organization-plan.md`：简短说明分类、命名和冲突处理规则。

## 6. 一个故意埋入的坑

`附件.pdf` 只有“请看附件、Lily、0813”等无上下文信息，不能可靠判断属于客户、供应商还是内部项目。它必须进入 `NEEDS_REVIEW`，不能因为名字或联系人而擅自归类。

## 7. 验收方法

确认 `input/` 的 18 个文件名称和内容没有变化；`organized/` 有 18 个副本；索引逐一可追溯；版本文件没有被合并或覆盖；至少一个文件被明确标记为待人工确认。

## 8. 一句课堂收口

不要再人工一个个改文件名了——让 AI 整理，让人只处理它无法可靠判断的那几项。
