# 03｜Data Analysis → Dashboard

目标不是“在 Excel 放几张图”，而是把业务数据依次走完：数据理解 → 数据体检 → 分析 → 统计 → 找异常 → 选择图表 → 形成结论 → 生成可浏览 Dashboard。

## 开始前

先确认分析对象、关注时间、核心业务问题、关键指标口径、异常处理原则和受众。读取 `input/DATA_DICTIONARY.md` 与工作簿的 `README` sheet；不要直接跳到画图。

## 输入

- `input/business-performance.xlsx`
- 工作簿包含虚构 BrewGo 教学数据及少量有意植入的数据质量与业务异常。
- 金额字段按数据字典中的统一 USD-equivalent 教学口径；不得把当前数据外推为真实 BrewGo 或市场表现。

## 输出契约

只在 `outputs/` 创建：

- `analysis.md`
- `analysis.xlsx`
- `dashboard.html`

`analysis.md` 至少包含：数据范围、数据质量说明、主要指标、变化趋势、异常、可能解释、当前数据不能得出的结论、建议下一步验证。

`dashboard.html` 必须单文件、本地直接打开、不依赖服务器或在线 CDN、适合课堂投屏，并至少有 4 张真正回答业务问题的图。图表标题要表达问题，关键数字应能追溯到 `analysis.xlsx` 的汇总表或明确计算口径。

## 分析边界

- 不隐藏重复、空值或异常高值；说明如何处理及其影响。
- 相关变化不是因果。广告费用和订单、退货与区域同时变化时，只能提出待验证解释。
- 不为凑数量堆图；图形选择应匹配问题与数据类型。
- 不覆盖原始工作簿；清洗数据、公式、透视结果或图表数据写入输出工作簿。

## 完成前自检

核对指标分母、时间粒度、币种 / 单位、重复处理、缺失值、异常值、图与结论一致性、Dashboard 离线依赖和人工验证项。
