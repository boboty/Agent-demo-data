# Day2 Live Task 工作区规则

- 开始执行前先读取 `RAW_REQUEST.md`，不要把模糊原始需求直接当成最终任务。
- 先提出会改变执行口径、范围或验收结果的澄清问题；得到回答后，先复述最终任务定义再执行。
- `input/` 是只读原始输入。不得覆盖、改名、删除或在原文件中“修正”数据。
- 所有结果只写入 `outputs/`；执行前不要假设其中已有答案。
- Live 数据与 Offline 教学数据必须明确区分。切换数据源时，在结果中记录原因。
- 不补造缺失字段，不把推测写成事实。缺失时留空、写 `unknown` 或进入人工复核项。
- 对关键结论保留来源、口径、采集 / 分析时间和限制。
- 任何关注、私信、发布、购买、改价或批量营销动作都不在本任务授权范围内。
- 完成前按任务 README 的输出契约自检；人工决策项不得冒充已完成动作。
