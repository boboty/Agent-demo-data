确认商品事实

03 / DEFINE

定义 5+N 分析维度

5 个固定对比维度

  1. 质量 Quality
  2. 价格 Price
  3. 包装 Packaging
  4. 材质 Material
  5. 功能 Function
固定维度不可修改或删除。“N” 为 3–5 个品类专属变量，可在左侧定义。
