# BrewGo Codex Workspace Guide

本工作区用于 BrewGo G2 虚构业务课堂。开始任务前阅读 project-context.md，以及 business/ 中与任务相关的文件，再检查 input/ 中的当前任务材料。

- business/ 与 input/ 是生成的只读课堂材料，不得覆盖、删除或原地修改。
- 不补造产品、市场或经营事实；资料不足或冲突时明确标记待确认，推测必须写明依据。
- 结果只写入 outputs/，并为重要结论保留来源文件或事实依据。
- 广告否定、预算、出价等线上业务动作只输出建议，必须人工确认。
- 若用户要求把工作方法沉淀成 Skill，创建在当前 workspace 的项目级 `.agents/skills/<skill-name>/`，不写入全局 `~/.codex/skills`。
- 完成前自检事实来源、输出文件和人工确认边界。
